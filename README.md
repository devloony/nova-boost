# NOVA BOOST — Telegram Mini App

Стартовый MVP Mini App для бустов Standoff 2.

## Что уже есть

- 3 раздела: Главная / Отзывы / Предложения
- выбор текущего звания
- выбор желаемого звания
- звания: Phoenix → Ranger → Champion → Master → Elite → Legend
- нельзя выбрать желаемое звание ниже или равное текущему
- кнопка заказа
- заготовка API `/api/order`
- Telegram WebApp API
- ваш логотип и фон уже положены в `public/`
- адаптация под телефон

## Запуск

1. Установить Node.js.
2. В папке проекта выполнить:
   `npm install`
3. Создать `.env` на основе `.env.example`.
4. В `BOT_TOKEN` вставить токен бота от BotFather.
5. В `WEBAPP_URL` указать HTTPS-адрес, где будет доступен Mini App.
6. Запустить:
   `npm start`

Для Telegram Mini App нужен публичный HTTPS-адрес. Для теста можно использовать любой HTTPS tunnel.

## Важно

Сейчас это именно рабочая заготовка интерфейса. Реальная оплата, база заказов, админка и загрузка отзывов пока не подключены.
